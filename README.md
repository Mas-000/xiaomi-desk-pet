# 小咪 · 桌面 AI 互動角色

零框架原生 JavaScript 打造的 60fps 桌面虛擬角色，含 LLM 對話與情緒動畫系統。

**▶ 線上試玩：** https://mas-000.github.io/xiaomi-desk-pet/

打開即可互動，**不需要任何 API 金鑰**——預設為本地規則模式。若填入自己的 Gemini 金鑰，會切換成 LLM 對話模式（金鑰只存在瀏覽器本機的 localStorage，不會送到任何第三方伺服器）。

---

## 這個專案在做什麼

把一個不可靠的雲端 LLM，包進一個必須隨時都能動的桌面角色裡。

難點不在「串 API」，而在**串不上的時候要怎麼辦**——所以整個系統的設計重心是降級路徑與動畫品質的驗證方法。

## 功能

- **情緒動畫狀態機**：10 種情緒 × 8 種待機動作，含三組不同勁度的彈簧物理與關鍵影格內插，60fps 主迴圈
- **口型同步（視覺）**：打字機式逐字揭示，每個字查注音韻母挑選對應嘴型
- **LLM 對話**：串接 Gemini 結構化輸出，以 JSON Schema 強制回傳 `{emotion, intensity, reply}`，情緒標籤限定為 enum
- **四層降級**：四個模型依序 fallback，逾時中斷；全部失敗時退回本地規則引擎，**斷網下功能不中斷**，並將當前模式即時顯示於 UI 左上角
- **導覽模式**：網址加上 `?tour=1` 會自動演示一輪，不需金鑰

## 技術

`原生 JavaScript`（無框架、無打包工具）· `Canvas 動畫` · `Gemini API` · `Electron`（桌面版）· `Playwright`（視覺回歸）

一份核心邏輯支援三種外殼：Electron 透明置頂桌面版、單檔 HTML、手機瀏覽器版。

## 動畫要怎麼測？

動畫的缺陷單元測試抓不到——「這個眉毛角度看起來對不對」沒有斷言可以寫。

所以另外自建了一套 Python + Playwright 的視覺回歸工具鏈：截圖數像素、量動畫頻率、對每個動畫參數做 A/B 比對驗收（眉毛五種狀態、眼瞼開合、視線方向、實際顯示尺寸）。
